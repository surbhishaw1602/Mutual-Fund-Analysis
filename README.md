# 📊 Mutual Fund Analysis

End-to-end Mutual Fund Analysis using **Python, Excel & Power BI**.

---

## 📌 Overview

This project analyzes mutual fund data from the Indian market using three tools in sequence:

- **Python** for data cleaning and exploratory analysis
- **Excel** for summarizing and ranking the top-performing funds
- **Power BI** for an interactive dashboard with key insights

## 🎯 Objective

To understand how mutual funds differ in size, cost, risk, and returns, so investors can compare fund types, fund houses, and fund managers.

---

## 📁 Project Structure

| File | Description |
|---|---|
| `Mutual_Funds.csv` | Raw dataset of mutual fund schemes |
| `Mutual_Fund_Analysis.ipynb` | Python notebook for cleaning, exploration, and analysis |
| `top_30_mutual_funds.xlsx` | Excel file listing the top 30 funds |
| `Mutual_Fund_Dashboard.pbix` | Interactive Power BI dashboard |
| `Mutual_Fund_Dashboard_.png` | Dashboard screenshot |
| `README.md` | Project documentation |

---


## 📈 Dashboard Highlights

- **KPI cards:** Total fund size, total lumpsum amount, total SIP investment, average expense ratio (0.71), average fund age (8.32 years), and average 1-year return (3.92)
- **Investment volume by fund type:** Equity (1.35M Cr) leads, followed by Debt (1.18M Cr) and Hybrid (0.46M Cr)
- **1-year returns by fund house:** Bank of India Mutual Fund is highest (14.4), followed by HDFC (7.3), ICICI Prudential (5.8), Nippon India (4.9), and SBI (3.9)
- **Top fund managers by assets:** Vivek Sharma manages the most (7.3K Cr), followed by Vishal Mishra (4.7K Cr)
- **Average expense ratio by strategy:** Index Funds (0.26) are among the cheapest, and Fixed Maturity Plans are as low as 0.05
- **Fund count by investment type:** Equity 37.84%, Debt 34.64%, Hybrid 14.25%, Other 9.83%
- **Interactive filters:** Fund house, scheme name, and fund type

---

## 🔍 Key Insights

- Equity funds have the largest fund size and the highest 3-year returns.
- Index funds have the lowest expense ratios among major categories (about 0.26%).
- Bank of India Mutual Fund offers the highest 1-year return (14%).
- Average SIP amount is about ₹528, and average minimum lumpsum is about ₹3.05K.
- Hybrid funds contribute about 14.25%, balancing risk and reward.
