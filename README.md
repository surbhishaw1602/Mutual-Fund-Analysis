# Mutual-Fund-Analysis

Overview

This project analyzes mutual fund data from the Indian market using three tools in sequence: Python for cleaning and exploration, Excel for summarizing the top performers, and Power BI for an interactive dashboard. It was built by Nirav Trivedi, as credited on the dashboard.

Objective

To understand how mutual funds differ in size, cost, risk, and returns, so investors can compare fund types, fund houses, and fund managers.

Project Components
File	Purpose
Mutual_Funds.csv	Raw dataset of mutual fund schemes
Mutual_Fund_Analysis.ipynb	Python notebook for data cleaning, exploration, and analysis
top_30_mutual_funds.xlsx	Excel file listing the top 30 funds
Mutual_Fund_Dashboard.pbix	Interactive Power BI dashboard
Mutual_Fund_Dashboard_.png	Screenshot of the dashboard
Dashboard Highlights

The dashboard, titled "Mutual Fund Overview & Insights", includes:

KPI cards: total fund size (about 3M Cr), total lumpsum amount, total SIP investment, average expense ratio (0.71), average fund age (8.32 years), and average 1-year return (3.92)
Investment volume by fund type: Equity (1.35M) leads, followed by Debt (1.18M) and Hybrid (0.46M)
1-year returns by fund house: Bank of India Mutual Fund is highest (14.4), followed by HDFC (7.3), ICICI Prudential (5.8), Nippon India (4.9), and SBI (3.9)
Assets managed by top fund managers: Vivek Sharma manages the most (7.3K Cr), followed by Vishal Mishra (4.7K Cr)
Average expense ratio by fund strategy: Index Funds are cheapest at 0.26, and Fixed Maturity Plans go as low as 0.05
Fund count by investment type: Equity 37.84%, Debt 34.64%, Hybrid 14.25%, Other 9.83%
Interactive filters: fund house, scheme name, and fund type
Key Insights
Equity funds hold the largest share of assets and also show the highest 3-year returns.
Index funds and money market funds have the lowest management fees.
Average SIP amount is about ₹528 and average minimum lumpsum is about ₹3.05K.
Hybrid funds balance risk and reward, contributing about 14% of the total.
Tools and Skills Demonstrated
